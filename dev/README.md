# dev/

Implementation planning 산출물을 보관하는 영역이다.
현재 repo 는 code implementation 을 시작하지 않고, `dev/<nf>/` 아래에 architecture-derived plan, task graph, test matrix, traceability 를 먼저 둔다.

현재 산출물.

- `dev/nssf/implementation-plan.md`
- `dev/nssf/tasks.yaml`
- `dev/nssf/test-matrix.md`
- `dev/nssf/traceability.md`

소스 코드, build system, dependency file 은 `/nf-impl-plan` 단계에서 만들지 않는다.
