## One-line Summary
NSSF 가 노출하는 두 SBI 서비스(Nnssf_NSSelection, Nnssf_NSSAIAvailability)의 stage 3 정의 — HTTP/2·JSON 위의 메시지·자료형·URI 를 명세한다.

## 1. Document Information
- 발행: 3GPP, 2026-03 (Rel-19, V19.6.0)
- 시리즈: TS 29.531
- 담당 WG: 3GPP CT4 (Service Layer Architecture)
- 분량: 추출본 기준 약 120 KB. 본 spec 끝에는 Annex A (OpenAPI) 와 Annex B (informative change history) 가 따른다.

## 2. Key Contributions
- Nnssf_NSSelection 서비스(GET 단일 operation) 정의. AMF·SMF+PGW-C·NWDAF·vNSSF 가 슬라이스 선택 정보(Allowed/Configured NSSAI, target AMF Set, NSI ID, S-NSSAI mapping)를 한 호출로 가져온다.
- Nnssf_NSSAIAvailability 서비스(Update / Subscribe / Unsubscribe / Notify / Delete / Options 6 operation) 정의. TA 단위 S-NSSAI 가용성 등록·갱신과 이벤트 통지 채널 제공.
- 구독 가능한 이벤트 4종 명시. NSSAI availability 변경, Network Slice Replacement, Network Slice Instance Replacement, NSSAI validity time 변경.
- NSAG (Network Slice AS Group) 정보 처리 — Configured NSSAI 와의 연관, Subscribe/Update 양쪽 메시지에서 일관 표현.
- VPLMN ↔ HPLMN S-NSSAI mapping 제공 — Indirect Network Sharing, EPC PDN Connection Establishment 시나리오 포함.
- HTTP redirection 정의. `3gpp-Sbi-Target-Nf-Id` 헤더 기반 NSSF set 내 redirection.
- supportedFeatures 협상(`6.1.8`, `6.2.8`), ProblemDetails (RFC 9457) 에러, JSON Patch (RFC 6902) update.

## 3. Methodology and Architecture
NSSF 는 5GC 의 service based architecture 안에서 Nnssf SBI 한 개로 외부에 노출된다. Consumer 는 AMF, SMF+PGW-C, NWDAF, 그리고 다른 PLMN 의 NSSF (vNSSF/hNSSF) 다. NF discovery 는 NRF 또는 local configuration 으로 이루어지고, 홈 NSSF 주소는 visited NSSF 의 local config 또는 TS 23.003 self-constructed FQDN 으로 결정된다.

API 진입점은 두 개다.
- Nnssf_NSSelection — `{apiRoot}/nnssf-nsselection/v2`
- Nnssf_NSSAIAvailability — `{apiRoot}/nnssf-nssaiavailability/v1`

전송은 HTTP/2 (RFC 9113), 페이로드는 JSON (RFC 8259). 에러는 ProblemDetails (RFC 9457). Update 의 부분 변경은 JSON Patch (RFC 6902). 보안은 OAuth 2.0 (RFC 6749) 와 TS 33.501 의 5GC 보안 아키텍처를 따른다. OpenAPI 3.0.0 정의는 Annex A 에 동봉.

## 4. Key Procedures and Messages

### 서비스별 operation 매트릭스

| Service | Operation | HTTP | 핵심 입력 | 핵심 출력 |
| --- | --- | --- | --- | --- |
| Nnssf_NSSelection | Get | GET | Requested/Subscribed NSSAI, PLMN ID, TAI, NF type, Requester ID, sNssaiForMapping (옵션) | Allowed NSSAI, target AMF Set / candidate AMF list, Configured NSSAI, Target NSSAI, NSI ID, S-NSSAI mapping |
| Nnssf_NSSAIAvailability | Update | PUT / PATCH | NssaiAvailabilityInfo (per `{nfId}`), 또는 PatchDocument | AuthorizedNssaiAvailabilityData |
| Nnssf_NSSAIAvailability | Subscribe (create) | POST | NssfEventSubscriptionCreateData (events 포함) | NssfEventSubscriptionCreatedData + Location URI |
| Nnssf_NSSAIAvailability | Subscribe (modify) | PATCH | PatchDocument (event IE 변경 금지) | NssfEventSubscriptionCreatedData |
| Nnssf_NSSAIAvailability | Unsubscribe | DELETE | subscription URI | 204 No Content |
| Nnssf_NSSAIAvailability | Notify | POST (callback) | NssaiAvailabilityNotification | — |
| Nnssf_NSSAIAvailability | Delete | DELETE | NSSAI availability resource (per `{nfId}`) | 204 No Content |
| Nnssf_NSSAIAvailability | Options | OPTIONS | — | CORS / capability discovery |

### Get 호출이 사용되는 stage 2 절차

- Registration (TS 23.502 §4.2.2.2.2) / Registration with AMF re-allocation (§4.2.2.2.3)
- EPS↔5GS handover via N26 (§4.11.1.2.2) / EPS to 5GS mobility registration (§4.11.1.3.x)
- Xn / N2 Handover with PLMN change (§4.9.1, §4.23.7, §4.23.11)
- UE Configuration Update (§4.2.4.2)
- SMF selection — non-roaming/LBO (§4.3.2.2.3.2), home-routed roaming (§4.3.2.2.3.3)
- PDN Connection Establishment in EPC (§4.11.0a.5)
- Network Slice load analytics — NWDAF (TS 23.288 §6.3.4)

### Get 응답 코드
- 200 OK — slice 정보 또는 mapping 정보 검색 성공.
- 204 No Content — Update 결과 권한 가용성이 비었을 때.
- 403 Forbidden + ProblemDetails (`SNSSAI_NOT_SUPPORTED`) — 요청한 slice/mapping 정보를 찾지 못함.
- 307 / 308 — NSSF set 내 redirection (`3gpp-Sbi-Target-Nf-Id` 헤더).

## 5. Limitations and Open Issues
- Nnssf_NSSelection 에는 notification 이 정의되어 있지 않다 (clause 6.1.5).
- 본 spec 에는 binary data 가 사용되지 않는다 (clause 6.1.6.4) — JSON 단일.
- Annex B 가 informative change history 를 보관한다. 본 추출본 기준으로 변경 항목 자체의 자세한 표는 잘려있어, 정확한 Rel-18 → Rel-19 비교는 Annex B 원본 또는 별도 release notes 가 필요하다.
- 본 추출 범위 내에서 명시적 FFS / editor's note 는 발견되지 않았다.

## 7. Glossary
- **NSSF** — Network Slice Selection Function. 5GC 에서 슬라이스 선택을 담당하는 NF.
- **vNSSF / hNSSF** — visited / home NSSF (roaming 시 두 PLMN 의 NSSF).
- **NSI** — Network Slice Instance. 실제로 인스턴스화된 슬라이스 (NSI ID 로 식별).
- **NSSAI** — Network Slice Selection Assistance Information. S-NSSAI 의 집합.
- **S-NSSAI** — Single NSSAI. 슬라이스 한 개를 식별하는 단위 (SST + SD).
- **NSAG** — Network Slice AS Group. AS 계층에서 S-NSSAI 들을 묶어 단말 동작을 제어하는 단위.
- **NRF** — Network Repository Function. NF discovery 와 토큰 발급.
- **AMF / SMF / NWDAF / PGW-C** — 5GC 의 핵심 NF 들 (Access and Mobility / Session Management / Network Data Analytics / PDN Gateway control plane).
- **TA / TAI** — Tracking Area / Tracking Area Identity.
- **PLMN / VPLMN / HPLMN** — Public Land Mobile Network / visited / home.
- **SUPI** — Subscription Permanent Identifier.
- **ProblemDetails** — RFC 9457 의 HTTP 에러 응답 표현.
- **SBI** — Service Based Interface.
- **RSIPCE** — Roaming Slice Information for PDN Connection Establishment (feature, clause 5.2.2.2.5 에서 사용).
- **SATAS** — Subscription to AMF Set TAs (feature, clause 6.2.8 에서 사용).
- **SUMOD** — Subscription Modification (feature, clause 5.3.2.3.2 에서 사용).
- **SIOP** — Slice Information for Other Purposes (feature, clause 5.2.2.2.6 에서 사용).
- **ONSSAI** — (feature, clause 5.3.2.3.2 에서 사용) — empty taiList 허용.
